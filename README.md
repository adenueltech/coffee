### Coffee Haven - Responsive Coffee Shop Website





## Overview

Coffee Haven is a fully responsive, modern website for an artisanal coffee shop. The site features an elegant design with interactive elements
animations, and a 3D coffee cup model rendered using Three.js. The website is built with pure HTML, CSS, and JavaScript without any frameworks
demonstrating front-end development skills and responsive design principles.

## 🔥 Live Demo

[View Live Demo](https://coffee-wheat-omega.vercel.app/) 

## ✨ Features

- **Fully Responsive Design**: Optimized for all devices from mobile phones to large desktop screens
- **Interactive 3D Coffee Cup**: Rendered using Three.js with realistic materials and animations
- **Smooth Animations**: Page transitions and scroll reveal effects
- **Mobile-First Approach**: Ensures excellent user experience on all devices
- **Performance Optimized**: Fast loading times and smooth interactions
- **Cross-Browser Compatible**: Works on all modern browsers


## 🛠️ Technologies Used

- HTML5
- CSS3 (with modern features like Flexbox and Grid)
- Vanilla JavaScript (ES6+)
- Three.js for 3D rendering
- Font Awesome for icons
- Google Fonts

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic knowledge of HTML, CSS, and JavaScript if you want to modify the code


### Installation

1. Clone the repository:

```shellscript
git clone https://github.com/your-username/coffee-haven.git
```


2. Open the project folder:

```shellscript
cd coffee-haven
```


3. Open `index.html` in your browser or use a local development server:

```shellscript
# If you have Python installed
python -m http.server

# If you have Node.js installed
npx serve
```




## 📱 Responsive Design

The website is fully responsive with breakpoints at:

- Mobile: Up to 576px
- Tablet: 577px to 768px
- Laptop: 769px to 992px
- Desktop: 993px and above


## 🎨 Customization

### Colors

The website uses a coffee-themed color palette that can be easily customized by modifying the CSS variables in the `:root` selector:

```css
:root {
    --primary-color: #b45309;
    --primary-light: #d97706;
    --primary-dark: #92400e;
    --secondary-color: #78350f;
    --text-light: #fffbeb;
    --text-dark: #1c1917;
    --bg-light: #fffbeb;
    --bg-dark: #1c1917;
    --bg-medium: #f5f5f4;
}
```

### Fonts

The website uses the 'Poppins' font family from Google Fonts. To change the font, update the Google Fonts link in the `<head>` section and modify the `font-family` property in the CSS.
